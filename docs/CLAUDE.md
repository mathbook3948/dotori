# 문서 규칙

- 경로는 `docs/<domain>/<상세-제목>.md` 형식이다. 파일과 폴더 이름은 영어 소문자와 하이픈만 쓴다.
- 모든 문서는 아래 양식을 따른다.
- 문서에는 결정만 적는다. 배경은 1~3문장, 내용은 한 줄에 결정 하나다.
- 측정 수치, 버전 번호, 조사 과정, 코드나 설정에 이미 있는 것은 적지 않는다. 결정의 근거는 커밋 메시지에 남긴다.
- 문서를 추가하거나 지우거나 제목과 요약을 바꾸면 `mise run docs`로 `docs/README.md` 목록을 다시 만든다.

## 양식

```markdown
# <제목>

<이 문서가 무엇을 정하는지 한 문장>

- 상태: 초안 | 확정 | 폐기

## 배경

<왜 필요한지 1~3문장>

## 내용

<결정한 것. 한 줄에 하나>

## 미정

<아직 정하지 않은 것. 없으면 "없음">
```
