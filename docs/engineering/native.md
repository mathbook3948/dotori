# 운영체제 직접 호출

`unsafe` 코드를 어디에 두고 어떻게 감싸는지 정한다.

## 배경

창 아이콘처럼 안전한 바인딩이 없는 운영체제 기능이 있다. 모든 크레이트가 `unsafe`를 금지하므로, 그런 호출만 모아 둘 곳이 필요하다.

## 내용

- `unsafe` 코드는 `crates/native`에만 둔다.
- 다른 크레이트는 모두 `#![forbid(unsafe_code)]`를 유지한다.
- `crates/native`는 호출마다 받은 값을 먼저 검사하는 안전한 함수 하나로 감싼다.
- `unsafe` 블록마다 왜 안전한지 `SAFETY:` 주석으로 적고, 주석 금지 검사에서 빼도록 그 위에 `// ast-grep-ignore`를 단다.
- 그 운영체제가 아니면 함수는 아무것도 하지 않는다.
- 지금 있는 호출은 Windows 창의 작업 표시줄 아이콘을 바꾸는 것과, mimalloc이 쥔 빈 메모리를 돌려주는 것이다.
- 아이콘을 바꾸면 창이 돌려준 예전 아이콘을 지운다.
- 앱은 Windows에서만 창 핸들을 묻는다.
