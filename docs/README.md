# 문서

## 규칙

- 경로는 `docs/<domain>/<상세-제목>.md` 형식이다. 파일과 폴더 이름은 영어 소문자와 하이픈만 쓴다.
- 모든 문서는 아래 양식을 따른다.
- 문서를 추가하거나 지우면 이 파일의 목록을 함께 고친다.

## 양식

```markdown
# <제목>

<이 문서가 무엇을 정하는지 한두 문장>

- 상태: 초안 | 확정 | 폐기

## 배경

<왜 필요한지, 어떤 상황에서 나온 결정인지>

## 내용

<결정한 것>

## 미정

<아직 정하지 않은 것. 없으면 "없음">
```
