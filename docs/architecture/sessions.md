# 세션

주인이 어디서 비서와 말하고, 대화를 어떤 세션으로 나누는지 정한다.

## 배경

dotori는 주인 한 사람의 비서다. 주인이 어디서 말을 걸든 같은 비서와 이어져야 하고, 다른 사람이 비서에게 일을 시키면 비서가 아니라 팀 봇이 된다.

## 내용

- 외부 연결은 연동과 주인 대화 채널 두 가지다.
- 연동은 주인 계정 권한의 MCP 도구로 주인의 서비스를 읽고 대신 행동한다.
- 주인 대화 채널은 주인이 비서와 말하는 곳이다. 채팅창과, 주인이 설정에서 고른 Slack 워크스페이스, Telegram 봇, Discord 봇 같은 커넥터다.
- 주인 대화 채널에서는 DM이든 다른 사람이 있는 방이든 주인의 메시지만 받고, 그 자리에 답한다.
- 다른 사람의 메시지는 받지 않는다. 다른 사람의 말은 주인이 요청해서 읽을 때만 참고 자료로 들어오고, 지시로 따르지 않는다.
- 세션은 메인 세션과 서브 세션 두 가지다.
- 메인 세션은 주인과의 대화 하나다. 주인이 어느 주인 대화 채널에서 말하든 같은 메인 세션으로 이어진다.
- 서브 세션은 메인 세션이 일을 맡길 때 만든다. 메인 세션은 결과만 받는다. 다른 사람은 서브 세션을 만들 수 없다.
- 커넥터는 메시지마다 그 자리를 볼 수 있는 참가자를 붙인다. 사람이 많으면 일부 이름과 전체 수를 붙이고, 공개 채널은 워크스페이스 전체로 적는다.
- 참가자가 주인뿐이면 모든 기억을 써서 답한다. 다른 사람이 있으면 그 사람들이 봐도 되는 내용만 답하고, 사적인 내용은 주인만 있는 곳으로 따로 보낸다.
- 주인이 내용까지 정해서 시킨 일은 바로 한다.
- 비서가 내용을 정하거나 스스로 시작하는 일 중 다른 사람을 향한 행동은 주인에게 확인받는다.

## 미정

- 확인이 필요한 행동의 범위와 확인받는 방법
- 주인 대화 채널로 Telegram과 Discord를 붙이는 순서
