# 세션

대화를 어떤 세션으로 나누고, 각 세션이 무엇을 받고 무엇을 부르는지 정한다.

## 배경

주인과의 대화와 커넥터로 들어오는 대화가 한 맥락에 섞이면, 프로젝트 방에서 받은 질문에 주인이 하던 다른 일이 드러날 수 있다. 여러 사람이 동시에 말을 거는 곳도 커넥터다.

## 내용

- 세션은 메인 세션, 커넥터 세션, 서브 세션 세 가지다.
- 메인 세션은 앱 채널로 들어온 주인과의 대화 하나다. 채팅창과 `dotori chat`이 앱 채널이다.
- 커넥터 세션은 커넥터의 방마다 하나다. Slack은 DM과 채널, Telegram과 Discord는 방이 각각 하나의 커넥터 세션이다.
- 커넥터로 들어온 말은 주인의 말이어도 그 방의 커넥터 세션이 받는다.
- 커넥터 세션은 자기 방에만 답한다.
- 서브 세션은 메인 세션이나 커넥터 세션이 일을 맡길 때 만든다. 부른 세션은 결과만 받는다.
- 서브 세션은 자기를 부른 세션에만 결과를 돌려준다.
- 세션마다 대화 맥락은 따로 둔다. 모든 세션의 기록은 같은 원본 기록에 쌓인다.
- 메모와 기억 검색 범위는 [메모리](memory.md)에서 정한다.

## 미정

- 메인 세션이 커넥터 세션의 방에 말을 전하게 할 방법
- 커넥터 세션이 주인에게 알릴 일을 메인 세션에 전하는 방법
- 주인이 아닌 사람이 커넥터 세션에서 서브 세션을 만들게 할지
