# 세션

대화를 어떤 세션으로 나누고, 각 세션이 어떤 기억을 볼 수 있는지 정한다.

## 배경

비서는 하나이고 주인에 대해 다 알아야 한다. 하지만 다른 사람이 보는 곳에서는 그 사람들이 알아도 되는 것만 말해야 한다. 맥락을 나누는 기준은 채널이 아니라 누가 듣고 있느냐다.

## 내용

- 세션은 메인 세션, 방 세션, 서브 세션 세 가지다.
- 메인 세션은 주인만 보는 곳의 대화 하나다. 채팅창, 주인과의 DM처럼 주인만 있으면 채널이 달라도 같은 메인 세션으로 이어진다.
- 방 세션은 다른 사람이 보거나 말하는 곳마다 하나다. 채널, 그룹방, 다른 사람과의 DM이 방이다.
- 서브 세션은 메인 세션이나 방 세션이 일을 맡길 때 만든다. 부른 세션에만 결과를 돌려준다.
- 기억은 하나다. 메인 세션은 모든 기억을 본다.
- 방 세션은 그 방 사람들이 원래 볼 수 있던 기억과, 주인이 그 방에 공유한 것만 본다.
- 볼 수 있는 범위는 그래프 DB의 방과 권한 간선으로 정한다. 연결만으로는 권한이 생기지 않는다.
- 범위는 기억 검색 도구가 지킨다. 범위 밖의 기억은 방 세션의 맥락에 들어가지 않는다. 프롬프트로 막지 않는다.
- 프롬프트는 지금 방에 누가 있는지 알리고, 볼 수 있는 기억 안에서 어떻게 말할지를 정한다.
- 범위 밖의 정보가 필요하면 방 세션은 메인 세션을 통해 주인에게 묻는다.
- 주인은 메인 세션에서 방에 말을 전하거나 기억을 공유할 수 있다.
- 방 세션은 주인이 알아야 할 일을 메인 세션에 알린다.

## 미정

- 권한 간선을 정하는 규칙
- 방의 멤버가 바뀔 때 이전 기억을 볼 수 있게 할지
- 멤버를 다 알 수 없는 방을 다루는 방법
- 그래프 DB를 붙이기 전의 권한 처리
- 주인이 아닌 사람이 방 세션에서 서브 세션을 만들게 할지
