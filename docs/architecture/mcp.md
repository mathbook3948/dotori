# MCP

에이전트가 쓰는 도구를 어떻게 제공하는지 정한다.

## 배경

webfetch, browser 같은 도구를 직접 만들어서, 어느 실행기에서도 같은 도구를 쓰게 한다. 브라우저 로그인 상태도 유지해야 한다.

## 내용

- MCP 서버에는 모든 실행기가 함께 쓰는 공통 도구만 둔다. 브라우저와 webfetch처럼 로그인 세션 같은 상태를 함께 유지해야 하는 도구다.
- 파일과 셸 같은 기본 도구는 MCP 서버에 두지 않는다. 각 실행기가 자체로 갖는다.
- MCP 서버는 lightbot이 직접 만든다. 앱이 서버 프로세스를 하나만 띄우고, 메인 대화와 모든 하위 작업이 HTTP로 같이 쓴다.
- 서버가 브라우저와 브라우저 프로필을 계속 갖고 있어서 로그인 상태가 유지된다.
- 서버는 앱을 통해 사용자에게 요청을 보낼 수 있다. 요청을 보낸 도구는 사용자를 기다리지 않고 결과를 바로 돌려준다.

## 미정

- 로그인 방법: 앱 화면에 입력 카드를 띄울지, PC 브라우저 창에서 직접 로그인하게 할지
- 외부 MCP 서버 지원 방식
