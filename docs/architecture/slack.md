# Slack 연결

Slack 채널이 무엇을 듣고 어디에 답하는지 정한다.

## 배경

dotori는 개인 PC에서 돌아서 Slack이 부를 공개 주소가 없다. 다른 사람도 말을 걸 수 있지만, 비서에게 한 말이 아닌 대화까지 모두 받으면 메인 대화가 넘친다.

## 내용

- Socket Mode로 연결한다. 앱 토큰으로 연결을 열고, 봇 토큰으로 말한다.
- 두 토큰은 설정 파일에 쓰지 않는다. 설정에는 토큰이 든 환경 변수 이름만 적는다.
- 설정 파일에 `[slack]` 항목이 있을 때만 Slack을 연결한다. 토큰이 없으면 Slack만 끄고 데몬은 돈다.
- 주인은 설정에 적은 Slack 사용자 하나다. 다른 사람은 모두 주인이 아니다.
- 비서에게 온 DM과 채널에서 비서를 멘션한 메시지만 받는다. 봇의 메시지와 수정, 삭제 같은 이벤트는 받지 않는다.
- 받은 글의 Slack 표기(링크, 채널, 멘션)는 사람이 읽는 글로 풀어서 넘긴다.
- 답은 Slack 표기로 해석되지 않게 이스케이프한다. 비서의 답이 채널 전체를 부르거나 누군가를 멘션하지 않는다.
- 긴 답은 줄바꿈에서 나눠 여러 메시지로 보낸다.
- 채널에서 멘션받으면 그 메시지의 스레드에 답한다. DM은 대화에 바로 답하고, DM 스레드에서 온 말은 그 스레드에 답한다.
- 받은 봉투는 메시지를 넘기기 전에 확인 응답한다. Slack이 다시 보낸 메시지는 core가 메시지 id로 거른다.
- 연결이 끊기거나, 한동안 아무것도 오지 않거나, Slack이 끊겠다고 알리면 다시 연결한다. 잇따라 실패하면 기다리는 시간을 늘린다.
- 토큰이 더 이상 통하지 않을 때만 채널을 끝낸다.
- 보낸 메시지는 시간 초과로 실패해도 다시 보내지 않는다. 같은 답이 두 번 가는 것보다 낫다.
- 보낸 사람 이름은 Slack에서 잠깐만 물어 기억한다. 답이 없으면 사용자 id를 이름으로 쓴다.

## 미정

- 멘션 없이 비서가 들어간 채널의 대화를 맥락으로 받을지
- 설정창에서 Slack을 설정하는 방법
