# Telegram 연결

Telegram을 주인이 비서와 말하는 채널로 어떻게 쓰는지 정한다.

## 배경

주인은 휴대폰의 Telegram으로도 비서에게 말하고 싶다. dotori는 개인 PC에서 돌아서 Telegram이 부를 공개 주소가 없다.

## 내용

- 채널은 Bot API의 롱 폴링(`getUpdates`)으로 받는다. 공개 주소가 필요 없고, HTTP만으로 된다.
- 봇 토큰은 설정 파일에 쓰지 않는다. 설정에는 토큰의 이름만 적고, 값은 같은 이름의 환경 변수나 vault에서 읽는다.
- 설정 파일에 `[telegram]` 항목이 있을 때만 채널을 연결한다. 토큰이나 주인이 없으면 Telegram만 끄고 다른 채널과 데몬은 돈다.
- 주인은 설정에 적은 Telegram 사용자 id 하나다. 다른 사람과 봇의 메시지는 받지 않는다.
- 봇과의 개인 대화에서는 주인의 모든 글을 받는다. 그룹에서는 봇을 멘션하거나 봇의 말에 답한 주인의 글만 받고, 멘션은 떼고 넘긴다.
- 개인 대화는 주인만 읽는 방이다. 그룹은 멤버 수로 참가자를 적고, 세지 못하면 다른 사람이 볼 수 있는 방으로 다룬다.
- 그룹에서 받은 말에는 그 메시지에 답장으로 답한다. 주인에게만 보내는 답은 봇과의 개인 대화로 보낸다.
- 답은 서식 없이 보낸다. 비서의 답이 Telegram 서식으로 해석되지 않는다.
- 긴 답은 줄바꿈에서 나눠 여러 메시지로 보낸다.
- 연결이 실패하면 기다리는 시간을 늘려 다시 받는다. Telegram이 기다리라고 하면 그만큼 기다린다. 토큰이 더 이상 통하지 않을 때만 채널을 끝낸다.
- 설정창의 Telegram 카드에서 켜고 끈다. 봇을 만드는 안내, 주인의 사용자 id, 토큰을 넣는 가려진 칸을 보여 주고, 토큰이 환경 변수에서 오는지 vault에 있는지 알려 준다.
- `[telegram]`은 모델, Slack, 기억 검색처럼 모든 PC가 같게 나눈다.
