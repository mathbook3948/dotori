# 메모리

비서가 몇 달에서 몇 년 동안 기억을 유지하는 방법을 정한다.

- 상태: 초안

## 배경

비서는 최대한 모든 것을 기억해야 한다. 텍스트를 쌓기만 하면 오래 쓸수록 틀린 기억과 오래된 기억이 섞인다.

조사에서 확인한 점은 다음과 같다.

- 원본을 남기고 잘 찾는 방식이, 사실만 뽑아 정리하는 방식보다 같거나 더 많이 기억했다. 추출 과정에서는 뉘앙스가 사라졌다.
- 이사나 직장처럼 값이 바뀌는 사실은, 바뀔 때마다 갱신하는 방식이 원본 검색보다 나았다.
- 시간 정보가 없는 시스템은 시간을 묻는 질문에서 크게 틀렸다.
- 그래프의 효과는 사람과 사물의 연결, 시간 순서 연결에서 나왔다.

## 내용

### 층

| 층 | 내용 | 저장 |
|---|---|---|
| 원본 기록 | 비서가 받은 메시지, 비서의 답과 행동, 하위 작업 결과. 시간, 채널, 장소, 말한 사람, 역할을 함께 둔다. | SQLite |
| 그래프 | 대상(사람, 장소, 일), 별칭, 관계 사실, 언급 | [그래프 DB](graph.md) |
| 프로필 | 본인에게서 나온 현재 핵심 사실 일부. 크기 제한이 있다. | 그래프에서 만든다 |
| 색인 | 키워드 색인, 임베딩 벡터 | SQLite |

- 원본 기록은 고치지 않는다. core의 대화 저장소 역할도 한다. 재시작하면 여기서 대화를 이어 받는다.
- 관계 사실은 유효 시작과 끝, 대체한 사실, 근거 기록, 출처(본인, 다른 사람, 도구)를 갖는다.
- 그래프와 색인은 원본에서 다시 만들 수 있다.

### 쓰기

- 원본 기록은 메시지가 들어오는 즉시 저장한다.
- 대상과 관계 사실은 백그라운드 작업이 싼 모델로 뽑는다. 메인 루프를 막지 않는다.
- 사용자가 기억해 달라고 하면 도구로 바로 저장한다.
- 바뀐 사실은 덮어쓰지 않는다. 이전 사실의 유효 기간을 끝내고 새 사실과 연결한다.
- 웹페이지와 도구 결과는 사실을 직접 쓰지 못한다.

### 읽기

- 프로필은 항상 시스템 프롬프트에 넣는다.
- 나머지는 검색 도구로 꺼낸다. 검색어, 시간 범위, 대상을 조건으로 받는다.
- 검색 결과에는 원본 기록 링크를 붙인다.
- 모델은 검색어를 바꿔 가며 여러 번 찾을 수 있다.

### 정리와 잊기

- 주기적인 작업이 중복 대상을 합치고, 바뀐 사실을 대체한다.
- 한 번 정리할 때 기존 항목을 많이 잃으면 그 결과를 반영하지 않는다.
- 다른 사람에게서 나온 사실은 저장하되 프로필에 자동으로 올리지 않는다.
- 지우기는 사용자가 요청할 때만 한다. 사람이나 대화를 잊으면 거기서 나온 그래프, 색인, 프로필도 함께 지운다.

### 검색과 언어

- 키워드 검색은 형태소 분석기(lindera)로 조사와 어미를 떼고 SQLite FTS5에 넣는다.
- 형태소 분석기는 문자 종류로 언어를 나눠 사전을 고른다. 언어를 추가하면 사전만 추가한다.
- 사전은 실행 파일에 넣지 않고 파일로 불러온다.
- 임베딩 모델은 제품 언어 설정 하나에 맞춰 하나만 쓴다. 다른 모델이 만든 벡터끼리는 비교할 수 없기 때문이다.

| 언어 설정 | 모델 | int8 크기 | 라이선스 |
|---|---|---|---|
| 한국어 | KoEn-E5-Tiny | 38MB | Apache-2.0 |
| English | snowflake-arctic-embed-s | 34MB | Apache-2.0 |

- 로컬 모델은 100MB 이하만 쓴다.
- 사용자는 로컬 모델 대신 API 임베딩을 고를 수 있다.
- 벡터마다 어떤 모델로 만들었는지 기록한다. 설정이 바뀌면 백그라운드에서 다시 임베딩한다.
- 키워드 결과와 임베딩 결과는 순위를 합쳐서(RRF) 돌려준다.

### 평가

- 실제 사용에서 질문과 정답을 모아 평가 세트를 만든다. 여러 단계를 거치는 질문, 시간 질문, 사람 질문을 나눠 둔다.
- 모델 선택과 검색 방식 변경은 이 평가 세트로 판단한다.

## 미정

- 원본 기록 범위: 비서에게 온 메시지만 저장할지
- 기억 보기와 수정 화면
- 한국어와 영어 외 언어의 임베딩 모델
- KoEn-E5-Tiny의 영어 검색 성능, x86용 int8 변환
- 정리 작업의 주기와 사용할 모델
