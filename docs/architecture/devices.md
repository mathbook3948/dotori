# 여러 PC

여러 PC에 설치한 dotori를 비서 하나로 묶는 방법을 정한다.

## 배경

사용자는 여러 PC를 쓰고, 어느 PC에서 말을 걸든 같은 비서와 같은 기억으로 이어져야 한다. 개인 PC는 자주 꺼지거나 잠들고, 그래도 비서는 계속 답해야 한다.

## 내용

- 같은 프로그램을 여러 PC에 설치하고, 비서 하나로 묶는다.
- 묶인 PC 중 한 대가 본체다. 본체만 메인 대화, 커넥터, 브라우저, 그래프와 정리 작업을 맡는다.
- 사용자가 우선 본체와 넘겨받을 순서를 정한다. 우선 본체와 연락이 안 되면 다음 순서의 PC가 넘겨받고, 우선 본체가 돌아오면 돌려준다.
- 본체는 임대를 갖고 계속 갱신한다. 밖으로 무언가 보내기 전마다 임대가 아직 유효한지 확인한다.
- 임대 시간은 PC가 잠든 시간까지 세는 시계로 잰다.
- 본체를 정할 때 과반 동의를 요구하지 않는다. 연결이 끊긴 동안 본체가 둘이 될 수 있고, 다시 연결되면 원본 기록을 합친다.
- 다른 PC의 채팅창은 본체의 앱 채널에 연결한다.
- 다른 PC의 하위 작업은 본체의 MCP 서버를 쓴다.
- 커넥터가 받은 메시지는 본체의 메인 대화로 들어가고, 다른 PC의 채팅창에도 전파한다.
- 모든 PC가 원본 기록, 메모, 설정의 전체 사본을 갖는다.
- 복제는 파일이 아니라 기록 단위로 한다. 상대에게 없는 기록만 보낸다.
- PC마다 다른 PC의 기록을 어디까지 받았는지 기억하고, 다시 연결되면 그 뒤만 주고받는다.
- 새 PC는 처음 묶일 때 전체를 한 번 받는다.
- 원본 기록 항목의 번호는 만든 PC와 그 PC의 순번으로 정하고, 모든 PC에서 같다. 합칠 때는 합집합을 하이브리드 논리 시계 순서로 놓는다.
- 지우기 요청은 모든 PC에 전파한다.
- 키워드 색인은 PC마다 원본에서 만든다.
- 벡터는 본체만 만들고 다른 PC에 복제한다. 임베딩 API 비용이 PC 수만큼 늘지 않게 한다.
- 그래프는 본체가 채우고 다른 PC에 복제한다. 본체가 바뀌어도 그래프를 처음부터 다시 채우지 않는다.
- 봇 브라우저 세션은 본체에 하나만 둔다. 본체는 쿠키와 저장소를 암호화해 다른 PC에 계속 복제하고, 새 본체는 그 사본으로 시작한다.
- PC끼리는 Tailscale로 연결하기를 권장하고, IP와 포트로도 연결할 수 있다.
- PC끼리 주고받는 내용은 모두 암호화한다. 본체는 사용자가 승인한 PC만 받는다.

## 미정

- PC를 승인하는 방법과 암호화 키를 나누는 방법
- 하위 작업을 어느 PC에서 돌릴지 정하는 방법
- 본체가 둘인 동안 같은 이벤트를 두 번 받는 커넥터를 다루는 방법
- 그래프를 복제하는 방법
- 기억 검색을 연도별로 나눠 켜져 있는 PC들에게 맡길지
