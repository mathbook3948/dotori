# 여러 PC

여러 PC에 설치한 dotori를 비서 하나로 묶는 방법을 정한다.

## 배경

사용자는 여러 PC를 쓰고, 어느 PC에서 말을 걸든 같은 비서와 같은 기억으로 이어져야 한다. 개인 PC는 자주 꺼지거나 잠들고, 그래도 비서는 계속 답해야 한다.

## 내용

- 같은 프로그램을 여러 PC에 설치하고, 비서 하나로 묶는다.
- 메인 세션은 그 임대를 가진 PC 한 대에서만 돈다. 비서가 하나라서, 주인의 말이 없을 때 스스로 하는 일도 한 번만 한다.
- 다른 PC의 채팅창과 채널로 들어온 주인의 말은 메인 세션을 맡은 PC로 넘기고, 답은 받아서 그 자리에 보여 준다.
- 서브 세션은 어느 PC에서 돌든 결과를 메인 세션을 맡은 PC로 보낸다.
- 메인 세션을 이어받은 PC는 복제된 원본 기록에서 메인 세션을 이어 간다.
- 결과 없이 끊긴 도구와 서브 세션의 중단 기록은 그것을 시작한 PC가 남긴다.
- 한 번에 한 PC만 맡아야 하는 일은 일마다 임대를 둔다. 메인 세션, 채널의 연결, 브라우저, 벡터와 그래프를 만드는 작업이 여기에 든다.
- 임대는 먼저 잡은 PC가 맡는다. 일마다 맡은 PC가 다를 수 있다.
- 임대를 가진 PC는 계속 갱신한다. 갱신이 끊겨 임대가 끝나면 먼저 잡은 다른 PC가 이어받는다.
- 임대를 가진 PC는 밖으로 무언가 보내기 전마다 임대가 아직 유효한지 확인한다.
- 임대 시간은 PC가 잠든 시간까지 세는 시계로 잰다.
- PC가 잠들거나 꺼지기 전에는 가진 임대를 먼저 내려놓는다. 다른 PC가 임대 시간을 기다리지 않고 바로 이어받는다.
- 임대를 정할 때 과반 동의를 요구하지 않는다. 연결이 끊긴 동안 같은 일을 두 PC가 맡을 수 있고, 다시 연결되면 원본 기록을 합친다.
- 임대가 없는 일은 각 PC가 직접 한다. 채팅창, 서브 세션, 기억 검색, webfetch가 여기에 든다.
- 채팅창은 자기 PC의 앱 채널에 연결한다.
- 브라우저 도구 호출은 브라우저를 맡은 PC로 보낸다.
- 모든 PC가 원본 기록, 메모, 설정의 전체 사본을 갖는다.
- 복제는 파일이 아니라 기록 단위로 한다. 상대에게 없는 기록만 보낸다.
- 기록은 쓰는 즉시 연결된 PC에 보낸다. 끊겼다 다시 연결되면 빠진 기록부터 받는다.
- 새 PC는 처음 묶일 때 전체를 한 번 받는다.
- 원본 기록 항목의 번호는 UUID v7이고, 모든 PC에서 같다. PC마다 번호가 거꾸로 가지 않게 만든다.
- 기록마다 만든 PC를 둔다. 다른 PC의 기록을 어디까지 받았는지는 그 PC의 마지막 번호로 기억하고, 다시 연결되면 그 뒤만 주고받는다.
- 저장된 기록과 재시작 뒤 이어 갈 대화는 번호 순서를 따른다.
- 지우기 요청은 모든 PC에 전파한다.
- 키워드 색인은 PC마다 원본에서 만든다.
- 벡터는 그 작업의 임대를 가진 PC만 만들고 다른 PC에 복제한다. 임베딩 API 비용이 PC 수만큼 늘지 않게 한다.
- 그래프는 그 작업의 임대를 가진 PC만 채우고, RhizoDB의 복제 기능으로 다른 PC에 복제한다. 임대가 넘어가도 그래프를 처음부터 다시 채우지 않는다.
- 봇 브라우저의 로그인 상태는 하나다. 브라우저를 맡은 PC는 쿠키와 저장소를 암호화해 다른 PC에 계속 복제하고, 이어받은 PC는 그 사본으로 시작한다.
- PC끼리는 Tailscale로 연결하기를 권장하고, IP와 포트로도 연결할 수 있다.
- PC끼리 주고받는 내용은 모두 암호화한다. 사용자가 승인한 PC만 묶인다.

## 미정

- PC를 승인하는 방법과 암호화 키를 나누는 방법
- 서브 세션을 맡을 PC를 고르는 방법
- 메인 세션의 임대 시간
- 두 PC가 같은 채널을 연결한 동안 같은 메시지를 두 번 받는 채널을 다루는 방법
- 기억 검색을 연도별로 나눠 켜져 있는 PC들에게 맡길지
