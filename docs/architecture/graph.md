# 그래프 DB

메모리의 대상과 관계를 저장하고 질의하는 그래프 DB를 Rust로 직접 만든다.

## 배경

메모리는 사람, 장소, 일과 그 관계를 오래 쌓고 빠르게 찾아야 한다. 가볍게 내장할 수 있고 안정된 그래프 DB가 없어서 직접 만든다.

## 내용

- 이름은 RhizoDB(crate `rhizodb`)이고, 별도 저장소에서 개발해 따로 배포한다.
- 메모리를 모르는 범용 그래프 DB다. dotori는 의존성으로 가져다 쓴다.
- 별도 서버 없이 프로그램 안에서 도는 내장형이다.
- 스키마 없는 속성 그래프다.
- 질의 언어는 GQL을 기준으로 한다.
- 디스크 저장은 redb에 맡기고, 저장 층은 trait 뒤에 둬서 바꿀 수 있게 한다.
- 값은 우리가 정한 형식으로 바이트로 저장하고, 형식에 버전을 붙인다.
- 여러 PC 사이의 복제를 RhizoDB가 제공한다.
- Cypher와 겹치는 부분은 openCypher TCK로 검증한다.
- 같은 질의를 LadybugDB에도 실행해 결과를 비교한다.
- 강제 종료 후 일관성 테스트와 파서 퍼징을 한다.
- 다른 프로젝트에서 가져온 코드와 테스트에는 출처와 라이선스를 남긴다.

## 미정

- GQL 기능별 지원 순서
- 벡터와 키워드 색인을 그래프 안에 둘지
