# 창

채팅창과 설정창이 어떻게 보이는지 정한다.

## 배경

주인은 하루에도 여러 번 채팅창을 연다. 비서다운 느낌이 들도록 창의 모양을 한 가지 규칙으로 맞춘다.

## 내용

- 색은 DESIGN.md의 테마 가운데 주인이 고른 것을 쓴다. 기본은 그래파이트다. 모든 창이 같은 테마를 쓴다.
- 설정창의 모양 카드에서 테마와 밝게, 어둡게, 시스템 따라를 고르면 바로 저장되고, 열린 창이 모두 바로 바뀐다.
- 테마의 색은 DESIGN.md에만 적고, 창의 코드는 거기서 만든다.
- 창의 표시는 도토리 로고이고, 밝은 모양과 어두운 모양에서 로고의 색을 따로 쓴다.
- 모양을 "시스템 따라"로 두면 시스템이 어두울 때 어두운 색으로 그리고, 시스템이 바뀌면 바로 따라간다.
- 설정 파일을 읽지 못하면 창은 지금 모양을 지킨다. 손으로 고치는 중인 파일 때문에 테마가 바뀌지 않는다.
- 모양을 고르면 창은 바로 바뀌고, 저장은 그리는 스레드 밖에서 고른 순서대로 한다. 다른 창은 설정 파일이 바뀐 것을 보고 따라간다.
- `primary`는 버튼 바탕과 목록 표시 같은 작은 표시에만 쓰고 글자색으로는 쓰지 않는다.
- 창 위에는 dotori 표시와 제목, 그 아래 한 줄 상태를 둔다. 채팅창의 상태는 연결 여부다.
- 주인의 말은 오른쪽 `primary` 말풍선, dotori의 답은 왼쪽 `surface` 말풍선이다.
- dotori의 답은 목록, 번호 목록, 제목, 굵은 글씨, 코드 같은 가벼운 마크다운을 꾸며서 보여 준다. 짝이 맞지 않는 표시는 쓴 그대로 둔다.
- 코드와 명령은 OS마다 정한 고정폭 글꼴로 보여 준다.
- 다른 채널의 대화는 말풍선과 다른 회색 카드로 보여 주고, 채널과 방과 말한 사람을 붙인다. 주인에게만 보낸 답은 방 대신 "주인에게만"으로 적는다.
- 대화가 없으면 무엇을 할 수 있는지 짧게 안내한다.
- 글은 띄어쓰기에서만 줄을 바꾼다. 한글 단어가 중간에서 끊기지 않는다.
- 입력창은 둥근 칸과 보내기 버튼이다. 연결이 끊기면 그 아래에 이유를 적는다.
- 입력창은 여러 줄을 받는다. Enter는 보내고 Shift+Enter는 줄을 바꾼다. 글이 길어지면 8줄까지 커지고, 그 뒤로는 칸 안에서 스크롤하며 커서를 따라간다.
- 말마다 시간을 적는다. 같은 쪽이 같은 분에 한 말이 이어지면 마지막 말에만 적고, 다른 채널의 카드는 카드마다 적는다. 시간은 그 말을 처음 보여 준 PC가 재고, 창은 이 PC의 시간대로 "오후 3:07"처럼 읽는다. 날이 바뀌면 "오늘", "어제", "11월 2일 월요일" 같은 줄을 넣는다.
- dotori가 허락을 기다리는 도구 호출은 주황 테두리 카드로 보여 준다. 서버와 도구 이름, 넘길 내용을 항목별로 적고 "거절"과 "허락" 버튼을 둔다. 정해지면 버튼 대신 "허락했어요"나 "거절했어요"를 적는다.
- 말풍선에 마우스를 올리면 "복사" 버튼이 나오고, 누르면 그 말 전체를 복사한다. 말풍선 안 글을 끌어서 일부만 고르지는 않는다.
- 설정창은 항목마다 이름, 입력 칸, 설명 한 줄을 둔다. 저장 결과는 아래쪽에 색으로 구분해 보여 준다.
- PC가 여럿 묶이면 채팅창 위쪽에 지금 어느 PC가 답하는지 보여 준다.
- 브라우저가 다른 PC에 있으면 브라우저 탭은 그 PC를 알려 준다.
- `DOTORI_THEME`에 테마 이름, `light`나 `dark`, 또는 `forest-dark`처럼 둘 다를 적으면 설정보다 그쪽을 쓴다. 그때 설정창의 모양 카드는 저장된 선택을 보여 주고, 창이 그 변수를 따른다고 적는다.
