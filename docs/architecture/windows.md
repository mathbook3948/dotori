# 창

채팅창과 설정창이 어떻게 보이는지 정한다.

## 배경

주인은 하루에도 여러 번 채팅창을 연다. 비서다운 느낌이 들도록 창의 모양을 한 가지 규칙으로 맞춘다.

## 내용

- 색은 도토리 갈색을 중심으로 한 따뜻한 색이다. 모든 창이 같은 테마를 쓴다.
- 시스템이 어두운 모양이면 어두운 테마로 그리고, 바뀌면 바로 따라간다.
- 창 위에는 dotori 표시와 제목, 그 아래 한 줄 상태를 둔다. 채팅창의 상태는 연결 여부다.
- 주인의 말은 오른쪽 갈색 말풍선, dotori의 답은 왼쪽 흰 말풍선이다.
- 다른 채널의 대화는 말풍선과 다른 회색 카드로 보여 주고, 채널과 방과 말한 사람을 붙인다. 주인에게만 보낸 답은 방 대신 "주인에게만"으로 적는다.
- 대화가 없으면 무엇을 할 수 있는지 짧게 안내한다.
- 글은 띄어쓰기에서만 줄을 바꾼다. 한글 단어가 중간에서 끊기지 않는다.
- 입력창은 둥근 칸과 보내기 버튼이다. 연결이 끊기면 그 아래에 이유를 적는다.
- 설정창은 항목마다 이름, 입력 칸, 설명 한 줄을 둔다. 저장 결과는 아래쪽에 색으로 구분해 보여 준다.
- PC가 여럿 묶이면 채팅창 위쪽에 지금 어느 PC가 답하는지 보여 준다.
- 브라우저가 다른 PC에 있으면 브라우저 탭은 그 PC를 알려 준다.

## 미정

- 여러 줄 입력
- 말풍선 안 글 선택과 복사
- 메시지 시간 표시
