# 창

채팅창, 설정창, 시작하기 창이 어떻게 보이는지 정한다.

## 배경

주인은 하루에도 여러 번 채팅창을 연다. 비서다운 느낌이 들도록 창의 모양을 한 가지 규칙으로 맞춘다.

## 내용

- 색은 DESIGN.md의 테마 가운데 주인이 고른 것을 쓴다.
- 기본은 도토리다.
- 모든 창이 같은 테마를 쓴다.
- 설정창 맨 위의 "이름과 아이콘" 카드에서 비서의 이름과 그림을 정한다.
- 이름을 비워 두면 Dotori다.
- 창 문구에서 비서를 가리키는 곳은 정한 이름을 쓰고, 조사는 이름의 끝소리에 맞춘다.
- 프로그램을 가리키는 곳(다시 시작, 창 제목, 다른 PC의 dotori)은 dotori로 둔다.
- 그림은 주인이 올린 그림을 사진의 방향대로 세워 가운데 정사각형으로 잘라 작은 PNG로 `icons` 폴더에 두고, 둥글게 잘라 그린다.
- `icons` 폴더에는 쓰는 그림과 최근 그림 몇 개만 남긴다.
- 그림을 정하지 않으면 도토리 로고를 그리고, "도토리로 되돌리기"로 언제든 돌아간다.
- 그림과 로고는 창에 그려지는 크기의 두 배로 만들어 창에 넘긴다.
- 그림은 고르면 바로 저장되고, 이름은 저장을 누르면 저장된다.
- 열린 창은 설정 파일이 바뀌면 이름과 그림을 바로 다시 그린다.
- 모델에게 주는 지시문에도 정한 이름을 넣고, 이것은 dotori를 다시 시작하면 적용된다.
- 설정창의 테마 카드에서 테마와 밝게, 어둡게, 시스템 따라를 고르면 바로 저장되고, 열린 창이 모두 바로 바뀐다.
- 테마의 색은 DESIGN.md에만 적고, 창의 코드는 거기서 만든다.
- 창의 표시는 도토리 로고이고, 밝은 모양과 어두운 모양에서 로고의 색을 따로 쓴다.
- 모양을 "시스템 따라"로 두면 시스템이 어두울 때 어두운 색으로 그리고, 시스템이 바뀌면 바로 따라간다.
- 설정 파일을 읽지 못하면 창은 지금 모양을 지킨다.
- 손으로 고치는 중인 파일이 있어도 테마가 바뀌지 않는다.
- 모양을 고르면 창은 바로 바뀌고, 저장은 그리는 스레드 밖에서 고른 순서대로 한다.
- 다른 창은 설정 파일이 바뀐 것을 보고 따라간다.
- 주 버튼은 글자색을 채우고 바탕색으로 글자를 쓴다.
- 주 버튼은 한 화면에 하나만 둔다.
- `primary`는 진행 막대, 고른 것의 체크, 목록 표시, 고른 칸의 테두리 같은 작은 표시에만 쓰고, 글자나 버튼 바탕으로는 쓰지 않는다.
- 체크 칸은 체크되면 주 버튼의 색으로 채우고 바탕색으로 체크를 그린다.
- 채팅창에는 머리도 OS 제목 표시줄도 없다.
- 위쪽 얇은 줄 왼쪽에 설정 버튼, 오른쪽에 닫기 버튼을 둔다.
- 설정 버튼은 설정창을 따로 열고, 닫기 버튼은 채팅창을 닫는다.
- 그 줄을 잡고 창을 옮긴다.
- 로고는 답마다 붙은 로고가 대신한다.
- 창 바탕은 모든 OS에서 불투명한 단색이다.
- 카드, 입력 칸, 입력창, 목록은 `surface`에 옅은 두 겹 그림자를 두고 테두리를 두르지 않는다.
- 어두운 모양에서는 카드 위쪽 가장자리에 `rim`을 둔다.
- 카드 안에서 고른 것은 작은 그림자로 살짝 떠 있다.
- 허락을 기다리는 카드처럼 뜻이 있는 색의 카드는 그 색을 지키고 같은 그림자를 가진다.
- 위쪽 줄에는 글을 적지 않는다.
- 위쪽 줄은 창 끝에서 6px 아래부터 끌기 영역이다.
- 그 6px은 위쪽 가장자리로 크기를 바꾸는 자리로 남긴다.
- 창 버튼은 최소화와 닫기뿐이고, 창을 화면 가득 키우는 버튼은 두지 않는다.
- Windows에서는 최소화와 닫기를 OS의 캡션 버튼 영역으로 알린다.
- 창 버튼은 끌기 영역 밖에 둔다.
- 리눅스에서 직접 그릴 때도 세 버튼을 두고, 창이 화면 가장자리에 붙은 쪽으로는 크기를 바꾸지 않는다.
- 위쪽 줄을 두 번 눌러도 창을 키우지 않는다.
- macOS에서는 시스템의 창 버튼을 왼쪽에 그대로 두고 설정 버튼을 그 뒤에 둔다.
- 닫기는 시스템 버튼이 한다.
- 리눅스에서는 창 관리자가 직접 그리기를 받아 줄 때(컴포지터와 `_GTK_FRAME_EXTENTS`가 있는 GNOME, KDE 같은 환경)만 OS 제목 표시줄을 숨기고 닫기 버튼과 가장자리 크기 조절을 직접 한다.
- 그렇지 않으면 OS 제목 표시줄이 남고, 닫기는 그쪽에 맡긴다.
- 채팅창은 잘 될 때 상태를 적지 않는다.
- dotori에 닿지 않을 때만 입력창 아래 Enter 안내 대신 무슨 일인지와 할 일을 적는다.
- 켜는 중, 끊음, 닿지 않음을 나눠 적는다.
- 채팅창을 열었을 때 dotori가 꺼져 있으면 창이 dotori를 한 번 켜고, 그동안 켜는 중이라고 적는다.
- 연결된 뒤 dotori가 꺼지면 채팅창도 닫힌다.
- 데몬이 잠금을 잡았는데 연결 파일이 아직 없으면 켜는 중으로 본다.
- 어느 PC가 답하는지는 창에 적지 않는다.
- 상태를 색 점으로 보여 주지 않는다.
- 주인의 말은 오른쪽의 `bubble` 말풍선이다.
- dotori의 답은 말풍선 없이 바탕에 바로 쓰고, 답마다 첫 줄 옆에 작은 로고를 둔다.
- dotori의 답은 목록, 번호 목록, 제목, 굵은 글씨, 코드 같은 가벼운 마크다운을 꾸며서 보여 준다.
- 짝이 맞지 않는 표시는 쓴 그대로 둔다.
- 창의 글은 실행 파일에 넣은 카카오 작은글씨(Kakao Small Sans)로 쓴다.
- 카카오 작은글씨의 OFL 라이선스는 `crates/app/fonts/OFL.txt`에 둔다.
- 카카오 작은글씨의 합자는 꺼서 `->`나 `:-D`를 쓴 그대로 보인다.
- 코드와 명령은 OS마다 정한 고정폭 글꼴로 보여 준다.
- 다른 채널의 대화는 채널, 방, 말한 사람을 작은 흐린 줄로 위에 적고, 말은 그 아래 `surface` 카드에 둔다.
- 주인에게만 보낸 답은 방 대신 "주인에게만"으로 적는다.
- 카드와 버튼에는 테두리를 두르지 않고 바탕색으로 나눈다.
- 선은 머리와 대화, 대화와 입력창처럼 큰 영역 사이에만 쓴다.
- 대화가 없으면 무엇을 할 수 있는지 짧게 안내한다.
- 글은 띄어쓰기에서만 줄을 바꾼다.
- 한글 단어가 중간에서 끊기지 않는다.
- 입력창은 그림자가 옅은 둥근 칸과 둥근 보내기 버튼이고, 그 아래에 Enter 안내를 적는다.
- 입력창은 여러 줄을 받는다.
- Enter는 보내고 Shift+Enter는 줄을 바꾼다.
- 글이 길어지면 8줄까지 커지고, 그 뒤로는 칸 안에서 스크롤하며 커서를 따라간다.
- 말에는 시간을 늘 적지 않는다.
- 마우스를 올리면 그 말의 시간과 "복사"가 아래에 나온다.
- 그 줄은 비어 있을 때도 자리를 지켜서 마우스가 오가도 아무것도 밀리지 않는다.
- 시간은 그 말을 처음 보여 준 PC가 재고, 창은 이 PC의 시간대로 "오후 3:07"처럼 읽는다.
- 날이 바뀌면 "오늘", "어제", "11월 2일 월요일" 같은 줄을 넣는다.
- dotori가 허락을 기다리는 도구 호출은 `warn-soft` 바탕 카드로 보여 준다.
- 서버와 도구 이름, 넘길 내용을 항목별로 적고 "거절"과 "허락" 버튼을 둔다.
- 정해지면 카드는 `surface`로 돌아오고, 버튼 대신 "허락했어요"나 "거절했어요"를 적는다.
- 셸 명령이 샌드박스 안에서 돌 때만 명령 아래에 방패 표시와 함께 그렇다고 한 줄 적는다.
- "복사"를 누르면 그 말 전체를 복사한다.
- 말 안의 글을 끌어서 일부만 고르지는 않는다.
- 주인이 한 일은 바로 보인다.
- dotori 쪽에서 오는 답, 카드, 다른 채널의 말은 `motion.message-enter`로 흐려졌다가 `spacing.rise`만큼 올라오며 나타난다.
- 창을 연 뒤 데몬이 보내 주는 지난 대화는 움직이지 않는다.
- 데몬은 지난 대화를 다 보낸 뒤 `Live`를 보내서 그 경계를 알린다.
- 주인이 대화 끝을 보고 있으면 새 말을 `motion.follow`로 따라 내려간다.
- 위로 올려 읽는 중이면 그대로 둔다.
- 주인의 말은 언제나 끝으로 데려간다.
- 따라가는 동안 주인이 휠을 굴리면 멈춘다.
- 따라가기는 매 프레임 지금 자리에서 끝으로 다가간다.
- 지난 대화를 처음 그리는 중에 온 말도 위에서부터 훑어 내려가지 않는다.
- dotori가 생각하거나 도구를 쓰는 동안 대화 끝에서 로고가 `motion.working`으로 숨 쉬며 "생각하는 중"을 적는다.
- 일하는지는 데몬이 에이전트의 상태를 보고 `Working`으로 알려 주고, 창은 짐작하지 않는다.
- 주인의 허락을 기다리는 카드가 있으면 숨 쉬는 로고는 거둔다.
- 메인 세션을 돌리는 PC가 이 상태를 다른 PC에도 알려서, 어느 PC의 창에서도 같이 보인다.
- 답하는 PC가 바뀌면 그 전 PC의 상태는 거둔다.
- 대화 목록은 스크롤 영역째 따로 캐시되는 뷰로 그린다.
- "생각하는 중" 줄은 그 위에 떠서 마지막 말 바로 아래 자리에 놓이고, 목록 끝이 보이지 않으면 숨는다.
- 목록 아래에는 그 줄의 자리를 늘 비워 두어서, 줄이 나타나고 사라져도 목록이 움직이지 않는다.
- 그래서 로고가 숨 쉬는 동안 목록 전체를 매 프레임 다시 만들지 않는다.
- 마우스를 올리면 나오는 시간과 복사는 `motion.hover`로 나타난다.
- 움직임의 시간과 곡선은 `motion.rs`에 두고, 테스트가 DESIGN.md와 같은지 확인한다.
- ease-out은 GPUI의 `ease_out_quint`, ease-in-out은 `ease_in_out`이다.
- 설정창도 채팅창과 같은 바탕과 카드를 쓴다.
- 설정창의 위쪽 띠에는 "설정"과 창 버튼을 둔다.
- 설정창의 카드는 테두리 없이 면 색과 그림자로 구분한다.
- 설정창은 항목마다 이름, 입력 칸, 설명 한 줄을 둔다.
- 입력 칸은 테두리 없이 `surface` 카드로 보이고, 고른 칸만 `primary` 테두리를 보인다.
- 저장 버튼은 아래쪽에 선 없이 둔다.
- 설정창의 "안전하게 실행" 카드는 샌드박스가 켜져 있으면 `ok-soft` 상자로 그렇다고 적는다.
- Linux에서 꺼져 있으면 설치하면 무엇이 좋아지는지와 "샌드박스 환경 설치" 버튼을 두고, 관리자 확인이 필요하면 그렇다고 적는다.
- 설치하는 동안 버튼은 "설치하는 중이에요"로 멈추고, 실패하면 `danger-soft` 상자에 이유와 직접 실행할 명령, "명령 복사"와 "다시 해 보기"를 둔다.
- 카드는 샌드박스가 도는지 몇 초마다 다시 보고, 터미널에서 설치해도 켜진 것으로 바뀐다.
- Windows에는 이 카드가 없다.
- 설정창의 금고 카드는 "API 키와 토큰"과 "연동된 사이트"를 나눠 적는다.
- 금고 카드는 "안전하게 실행" 카드 바로 아래에 둔다.
- 금고 카드는 창이 열린 동안 금고가 바뀌면 다시 읽는다.
- 금고 카드의 줄은 자물쇠, 제목, 흐린 한 줄, 오른쪽의 버튼으로 이뤄지고, 보관됨이나 연동됨 같은 표시는 두지 않는다.
- 키 줄의 흐린 줄은 쓰는 곳이고, 환경 변수에서 읽는 키는 "환경 변수에서 읽어요"를 덧붙이고 버튼이 없다.
- 계정 줄의 제목은 호스트이고, 그 뒤에 흐린 글씨로 사이트 이름을 괄호에 넣는다.
- 계정 줄의 흐린 줄은 아이디다.
- 묻지 않고 로그인하는 계정에만 번개와 "묻지 않고 로그인" 표시를 둔다.
- 지우기와 연동 끊기는 휴지통 아이콘 버튼이다.
- 저장 버튼 옆에는 다시 시작하면 적용된다는 말이나 저장 결과를 보여 준다.
- 저장 결과는 색으로 구분해 보여 준다.
- PC가 여럿 묶이면 다른 PC가 답할 때만 머리 아래 줄에 그 PC를 적는다.
- 채팅창에는 브라우저 탭이 없다.
- dotori의 브라우저가 주인에게 부탁하면 대화 끝에 카드가 뜬다.
- 카드는 부탁한 말과 지금 화면을 16:10으로 보여 주고, "나중에"와 "브라우저 열기"를 둔다.
- 화면을 눌러도 열린다.
- "브라우저 열기"는 브라우저를 따로 창으로 열고 주인에게 넘긴다.
- 창이 열려 있는 동안 카드는 "창 다시 보기"와 "다 했어요"로 바뀐다.
- 브라우저 창의 "다 했어요"를 누르거나 창을 닫으면 브라우저를 dotori에게 돌려준다.
- 사이트가 로그인을 물으면 카드 안에서 아이디와 비밀번호를 받는다.
- 브라우저 창이 열려 있으면 그 창에서 받는다.
- "나중에"를 누르면 같은 부탁은 다시 보이지 않고, dotori가 다른 것을 부탁하면 다시 뜬다.
- 페이지가 파일을 달라고 해도 같은 카드가 뜬다.
- 브라우저 연결이 끊기면 카드는 거둔다.
- 카드는 브라우저 창이 열려 있는 동안 늘 "창 다시 보기"와 "다 했어요"를 보여 준다.
- 창이 닫히면 카드도 바로 바뀐다.
- 창을 닫을 때 브라우저를 돌려주는 일은 다음 틱에 한다.
- GPUI 0.2.2의 X11은 닫기 확인을 부르는 동안 상태를 빌려 두고 있어서, 그 자리에서 다시 그리면 멈춘다.
- 카드의 화면은 브라우저 창이 닫혀 있을 때만 그리고, 바뀐 화면을 그릴 때 이전 화면은 이 창에서 지운다.
- 화면은 0.5초에 한 번까지만 바꾼다.
- 카드가 떠 있는 동안에는 "생각하는 중"을 숨긴다.
- "나중에"로 거두면 다시 보인다.
- 브라우저가 칸을 채워 달라고 하면 대화 끝 가운데에 로그인 카드가 뜬다.
- 로그인 카드는 사이트의 그림이 아니라 제목, 브라우저가 지금 연 호스트, 안내 한 줄, 칸, 체크 칸, 버튼, 링크, 적은 것이 어디로 가는지 알리는 줄, "나중에 할게요"를 보여 준다.
- 비밀 칸은 가려진 칸이고, 인증번호 칸은 칸 이름을 안내 글로 보여 준다.
- 체크 칸은 페이지의 지금 상태로 시작한다.
- 카드가 뜨면 첫 칸에 커서가 간다.
- Enter는 다음 칸으로 가고, 마지막 칸에서는 버튼을 누른다.
- 버튼이나 링크를 누르거나 "나중에 할게요"를 누르면 카드는 바로 사라진다.
- 그때 적은 값은 창에서 지운다.
- 링크를 누르면 적은 값은 보내지 않는다.
- 금고의 계정으로 로그인해도 될지 묻는 카드는 허락 카드처럼 `warn-soft`다.
- 그 카드는 계정, "이 계정은 다음부터 묻지 않기", "거절", "로그인"을 둔다.
- 계정이 여럿이면 줄마다 라디오 버튼을 두고, 주인이 하나를 고른다.
- 그 카드는 계정을 호스트, 괄호 안의 사이트 이름, 아이디 순으로 적고, 채울 페이지의 호스트와 경로를 적는다.
- 처음에는 첫 계정이 골라져 있다.
- "이 계정은 다음부터 묻지 않기"는 처음에 꺼져 있다.
- 카드가 어떻게 됐는지는 `decision` 채널의 줄로 온다.
- 창은 그 줄을 자물쇠가 있는 한 줄 카드로 그린다.
- 링크를 누른 것, 나중에 하기로 한 것, 로그인을 거절한 것은 오른쪽의 흐린 한 줄로 적는다.
- 계정을 금고에 넣었으면 "연동됨" 줄과 "연동은 설정의 금고에서 언제든 끊을 수 있어요"를 덧붙인다.
- 창은 카드 번호와 HTTP 인증 로그인 번호를 따로 기억한다.
- 카드를 띄우지 못하거나 채우지 못한 결과는 창에 그리지 않고 모델이 주인에게 말한다.
- `DOTORI_THEME`에 테마 이름, `light`나 `dark`, 또는 `forest-dark`처럼 둘 다를 적으면 설정보다 그쪽을 쓴다.
- 그때 설정창의 테마 카드는 저장된 선택을 보여 주고, 창이 그 변수를 따른다고 적는다.
- 첫 실행을 마치지 않았으면 설정창 대신 시작하기 창(`dotori onboarding`)이 열린다.
- 시작하기 창은 마치지 않은 단계에서 다시 열리고, 앞 단계에서 저장한 것은 그대로 남는다.
- 첫 실행은 연결 화면이나 기존 PC 화면의 "대화 시작"을 누르면 끝난다.
- 시작하기 창은 설정창을 한 단계씩 걷는 같은 창이고, 저장도 설정창과 같다.
- API 키 단계의 다음은 모델의 주소와 키로 모델 목록을 물어 연결을 확인하고, 확인되면 저장하고 넘어간다.
- 연결이 안 되면 저장하지 않고, 키가 거절됐는지, 닿지 않았는지를 말한다.
- 확인하는 동안 "이전", 공급자 탭, 주소, 모델, 키 칸은 멈춘다.
- 확인된 값을 그대로 저장하고, 답이 오기 전에 단계가 바뀌었으면 답을 버린다.
- 저장된 키가 있으면 API 키 칸을 그 키로 채워 둔다.
- 모든 창은 `size.window`로 열린다.
- 채팅창과 설정창은 `size.window-min`까지 줄일 수 있다.
- 창과 그림의 크기, 그림 타일과 할 수 있는 일 타일의 색은 `tokens.rs`에 두고, 테스트가 DESIGN.md와 같은지 확인한다.
- 시작하기 창은 크기가 정해져 있고, 위쪽 줄에는 닫기 버튼만 있다.
- 화면은 인사, API 키, 이름과 테마, 연결 네 개이고, 한 화면에 하나만 보인다.
- 인사는 가운데에 선 도토리 타일, "안녕하세요, {이름}예요", 무엇을 하는지 두 줄, 할 수 있는 일 세 줄이다.
- 할 수 있는 일은 줄마다 색 타일 아이콘, 굵은 제목, 따옴표에 넣은 부탁 예시다.
- 인사를 열면 그림이 `motion.greet`로 내려와 앉고, 나머지가 차례로 `motion.message-enter`로 올라온다.
- 인사의 버튼은 "시작하기"다.
- 인사의 버튼 아래에는 조용한 글자 버튼 "기존 PC에 연결하기"가 있고, 누르면 기존 PC 화면이 열린다.
- 기존 PC 화면은 인사에서만 열리고, 진행 막대가 없다.
- 기존 PC 화면은 연결 코드와 주소 칸을 두고, 주소는 코드에 없을 때만 적는다.
- 연결은 설정창의 여러 PC 카드와 같은 방법으로 한다.
- 설정창의 여러 PC 카드는 이 PC의 이름 칸을 두고, 비어 있으면 칸에 컴퓨터 이름을 흐리게 보여 준다.
- PC 이름은 설정창의 저장 버튼으로 다른 설정과 함께 저장한다.
- 연결하는 동안 칸과 "이전"은 멈추고, 실패하면 칸 아래에 이유를 적고 칸을 다시 연다.
- 코드를 읽지 못하면 코드 칸을, 주소를 알 수 없으면 주소 칸을 `danger`로 두르고 그 칸 아래에 적는다.
- 기존 PC에 닿지 못했거나 코드를 거절당했으면 주소 칸 아래에 적는다.
- 연결되면 모델과 키가 이 PC에 들어왔는지 계속 보고, 들어오면 버튼이 "대화 시작"이 된다.
- 들어오기 전에는 버튼이 "설정과 키를 받고 있어요"로 멈추고, 그 아래 "여기서 직접 설정하기"가 API 키 화면으로 넘어간다.
- 기존 PC 화면의 "대화 시작"은 채팅창을 열고 시작하기 창을 닫는다.
- 나머지 세 화면 위에는 가는 진행 막대 세 개와 단계 이름을 두고, 지난 단계와 지금 단계를 `primary`로 채운다.
- 단계를 넘기면 화면 전체가 `motion.step`으로 흐려졌다가 나타나며, "다음"이면 오른쪽에서, "이전"이면 왼쪽에서 `spacing.slide`만큼 미끄러져 들어온다.
- 같은 시간 동안 새로 닿은 단계의 진행 막대가 왼쪽부터 채워지고, 되돌아가면 떠난 단계의 막대가 비워진다.
- API 키 화면은 Anthropic이면 키 칸만, OpenAI 호환이면 주소, 모델, 키 칸을 보인다.
- Anthropic을 고르면 설명 옆에 키를 만드는 페이지로 가는 "키 만들기"를 둔다.
- API 키 화면에 들어가면 키 칸에 커서를 둔다.
- API 키 화면은 키가 환경 변수나 vault에 있어야 넘어가고, 없으면 칸을 `danger`로 두르고 칸 아래에 이유를 적는다.
- 키가 필요 없는 OpenAI 호환 모델은 그냥 넘어간다.
- 시작하기 창에서는 vault를 "금고"라고 부르지 않고 "PC에 암호화되어 보관돼요"처럼 하는 일로 적는다.
- 이름과 테마 화면은 비서의 그림 타일 오른쪽 아래에 연필 배지를 늘 달고, 타일을 누르면 그림을 고른다.
- 테마는 설정창의 테마 카드와 같은 목록과 밝기 고르기를 쓴다.
- 연결 화면은 Slack, Telegram, Discord를 스위치로 켜고, 켠 것만 토큰과 내 ID 칸을 연다.
- 켠 채널은 토큰이 환경 변수나 금고에 있거나 칸에 적혀 있어야 넘어간다.
- 토큰은 켠 채널의 것만, 연결 화면에서만 금고에 넣는다.
- 연결 화면의 버튼은 "대화 시작"이고, 채팅창을 열고 시작하기 창을 닫는다.
- API 키 화면부터 "다음"은 설정창의 저장과 같은 저장을 하고, 실패하면 아래 줄에 적고 그 화면에 남는다.
- 시작하기 창에서는 "다시 시작하면 적용돼요"를 적지 않는다.

## 미정

- 입력창을 대화 위에 띄워 지나가는 글을 흐리게 비추는 것은 창 안 요소별 블러가 있어야 한다. GPUI 0.2.2에는 없어서 렌더러 패치가 필요하다.
- GPUI 0.2.2는 시스템의 움직임 줄이기 설정을 읽지 못한다. 읽을 수 있게 되면 그때 움직임을 제자리 바꿈으로 바꾼다.
- 버튼 색이 마우스에 따라 `motion.hover`로 바뀌는 것과 테마를 바꿀 때의 cross-fade는 아직 없다. 지금은 바로 바뀐다.
- 도구 호출을 한 줄로 접었다 펴는 모양은 창이 도구 호출을 받게 되면 만든다.
