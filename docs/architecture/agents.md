# 에이전트 실행

세션을 무엇으로 실행하는지 정한다.

## 배경

메인 세션은 API로 LLM을 부른다. 서브 세션은 큰 일이 많아서, 사용자가 구독 중인 코딩 에이전트에 맡길 수도 있게 한다.

## 내용

- LLM은 처음에 Anthropic과 OpenAI 호환 API를 지원한다.
- 기본값은 Anthropic의 Sonnet 5.5다.
- OpenAI 호환 API는 주소와 모델을 사용자가 정한다.
- 서브 세션 실행기는 처음에 LLM API, Claude Code CLI, Codex CLI를 지원한다.
- OpenCode, Cursor, Pi 같은 다른 코딩 에이전트는 실행기를 추가해서 붙인다.
- 메인 세션과 LLM API 실행기는 dotori 루프에서 돈다.
- 루프는 파일 읽기와 편집, 셸 실행 같은 기본 도구를 직접 갖고, MCP 서버의 공통 도구를 추가로 쓴다.
- 자세한 내용은 [MCP](mcp.md)에 있다.
- 기본 도구는 파일 읽기, 파일 쓰기, 파일 고치기, 셸 실행이다.
- 상대 경로와 셸은 메인 세션에서는 dotori의 작업 폴더, 서브 세션에서는 그 서브 세션이 일하는 폴더에서 시작한다.
- 셸은 입력 없이 돌며 시간 제한을 넘기면 띄운 프로세스까지 끝낸다.
- 셸에는 확인받는 도구가 쓰는 토큰을 넘기지 않는다.
- 메인 세션의 셸 실행, 파일 쓰기와 고치기는 채팅창 카드로 주인의 확인을 받는다.
- 파일 읽기는 확인받지 않는다.
- 기본 도구는 dotori 폴더 안에서는 작업 폴더만 다룬다.
- 코딩 에이전트는 자체 기본 도구를 쓰고, 같은 MCP 서버를 추가로 연결한다.
- 기능이 겹치는 도구는 끌 수 있으면 끄고, 끌 수 없으면 프롬프트로 MCP 서버의 도구를 쓰게 한다.
- 코딩 에이전트는 자동 승인 모드로 실행한다.
- Claude Code는 auto 모드, Codex는 `--approve-for-me`를 쓴다.
- 서브 세션 실행기는 설정에서 하나를 고른다.
- 고르지 않으면 LLM API 실행기를 쓴다.
- LLM API 실행기는 메인 세션과 같은 모델과 같은 종류의 도구로 서브 세션마다 새 대화를 연다.
- 브리프를 받은 스레드에 `say`로 답하고 도구를 더 부르지 않으면 끝난다.
- 결과는 Claude Code에서는 JSON 출력의 `result`로, Codex에서는 마지막 메시지 파일로 받는다.
- 서브 세션은 PC의 어느 폴더에서든 일할 수 있다.
- 메인 세션은 일을 맡길 때 그 일이 다루는 폴더를 적을 수 있고, 서브 세션은 실행기와 상관없이 그 폴더에서 일한다.
- 코딩 에이전트는 그 폴더에서 시작하고, LLM API 실행기는 그 서브 세션의 기본 도구를 그 폴더에 둔다.
- LLM API 실행기는 일하는 폴더를 브리프가 아니라 기본 도구의 설명으로 모델에게 알린다.
- 적지 않으면 dotori의 작업 폴더에서 시작하고, 없는 폴더를 적으면 시작하지 않는다.
- dotori의 작업 폴더가 아니면 숨김 폴더 안, 홈 폴더와 그 위, 홈의 AppData와 Library, 최상위 폴더, dotori 폴더에서는 서브 세션을 시작하지 않는다.
- MCP 서버의 토큰은 명령줄이 아니라 환경 변수로 넘긴다.
- MCP 서버가 죽었고 다시 뜨지 않으면 코딩 에이전트를 실행하지 않고 서브 세션을 실패로 돌려준다.
- 제한 시간을 넘긴 코딩 에이전트는 그것이 띄운 프로세스까지 함께 끝낸다.
- Claude Code의 WebFetch는 끄고 MCP 서버의 fetch_url를 쓰게 한다.
- 서브 세션의 중간 경과는 부른 세션에 알리지 않는다.
- 부른 세션은 결과만 받고, 기다리는 동안 다른 일을 한다.
- 자동 승인 모드가 없는 코딩 에이전트는 실행기로 붙이지 않는다.
- dotori는 서브 세션을 따로 격리하지 않는다.
- dotori가 직접 주는 툴은 동사로 시작하고, 동사만으로 모호하면 대상을 붙인다.
- 소문자와 `_`만 쓴다.
- 예: `add_routine`, `read_page`, `say`. 쓸 수 있는 동사는 `dotori_core::tool::TOOL_VERBS`에 있고, e2e 테스트가 실제로 모델에 가는 툴 이름을 모두 검사한다.
- 외부 MCP 서버의 툴은 `서버__툴`로 자기 이름을 그대로 둔다.
