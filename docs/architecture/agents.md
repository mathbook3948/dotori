# 에이전트 실행

메인 대화와 하위 작업을 무엇으로 실행하는지 정한다.

- 상태: 초안

## 배경

메인 대화는 API로 LLM을 부른다. 하위 작업은 큰 일이 많아서, 사용자가 구독 중인 코딩 에이전트에 맡길 수도 있게 한다.

## 내용

- LLM은 처음에 Anthropic과 OpenAI 호환 API를 지원한다.
- 기본값은 Anthropic의 Sonnet 5.5다. OpenAI 호환 API는 주소와 모델을 사용자가 정한다.
- 하위 작업 실행기는 처음에 LLM API, Claude Code CLI, Codex CLI를 지원한다.
- OpenCode, Cursor, Pi 같은 다른 코딩 에이전트는 실행기를 추가해서 붙인다.
- 메인 대화와 LLM API 실행기는 lightbot 루프에서 돈다.
- 루프는 파일 읽기와 편집, 셸 실행 같은 기본 도구를 직접 갖고, MCP 서버의 공통 도구를 추가로 쓴다. 자세한 내용은 [MCP](mcp.md)에 있다.
- 코딩 에이전트는 자체 기본 도구를 쓰고, 같은 MCP 서버를 추가로 연결한다.
- 기능이 겹치는 도구는 끌 수 있으면 끄고, 끌 수 없으면 프롬프트로 MCP 서버의 도구를 쓰게 한다.
- 코딩 에이전트는 자동 승인 모드로 실행한다. Claude Code는 auto 모드, Codex는 `--approve-for-me`를 쓴다.

## 미정

- 실행기마다 하위 작업 결과를 받아오는 방식
- 자동 승인 모드가 없는 코딩 에이전트(Pi 등)를 격리하는 방식
