# 개발 순서

dotori를 어떤 순서로 만드는지 정한다.

## 배경

core를 먼저 단단하게 만들고, 그 위에 연결과 기능을 붙인다. 그래프 DB는 core와 독립이라 함께 진행한다.

## 내용

- 1단계: core. 값 타입, 에이전트 부품, 루프 결정(step), 런타임, 원본 기록 저장 포트.
- 2단계: LLM 연결. Anthropic과 OpenAI 호환 API.
- 3단계: 데몬과 화면. 트레이, 앱 채널, GPUI 채팅창과 설정창.
- 4단계: Slack 커넥터.
- 5단계: MCP 서버. webfetch와 브라우저.
- 6단계: 서브 세션 실행기. LLM API, Claude Code CLI, Codex CLI.
- 7단계: 메모리. 그래프 채우기, 검색, 정리 작업.
- 그래프 DB는 1단계부터 따로 진행하고, 7단계 전에 쓸 수 있게 한다.
