# 제품 방향

lightbot이 어떤 제품인지 정의한다.

- 상태: 초안

## 배경

PC에서 24시간 돌아가는 가벼운 개인 비서를 만든다.

## 내용

- 트레이에 상주한다. 창을 닫아도 계속 실행된다.
- 화면은 GPUI로 만들고, 채팅창과 설정창을 둔다.
- 에이전트는 화면과 별도 루프에서 돈다. 화면은 블로킹되지 않는다.
- 대화는 채널로 들어온다. 앱 채팅창, Slack, Telegram 등을 연결할 수 있다.
- 메인 대화는 하나다. 어느 채널에서 말을 걸든 같은 대화로 이어진다.
- 본인 외의 사람도 말을 걸 수 있고, 비서는 다른 대화의 맥락도 파악한다.
- 메인 대화는 하위 작업을 만들고 결과만 받는다.
- 메모리는 핵심 기능이다.
- 의존성과 자원 사용을 작게 유지한다.
- LLM 프로바이더를 바꿔 쓸 수 있다.
- 하위 작업은 LLM API를 연결해서 lightbot이 직접 실행하거나, 사용자가 쓰는 코딩 에이전트에 맡길 수 있다.
- 브라우저 같은 공통 도구는 실행 방식과 상관없이 같은 것을 쓴다.
- 브라우저 로그인 상태를 유지하는 것을 목표로 한다.

## 미정

- GPUI와 트레이 아이콘 통합 방식
- 메모리 설계
