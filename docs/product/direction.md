# 제품 방향

dotori가 어떤 제품인지 정의한다.

## 배경

PC에서 24시간 돌아가는 가벼운 개인 비서를 만든다.

## 내용

- 트레이에 상주한다. 창을 닫아도 계속 실행된다.
- 화면은 GPUI로 만들고, 채팅창과 설정창을 둔다.
- 에이전트는 화면과 별도 프로세스에서 돈다. 화면은 블로킹되지 않는다.
- 화면이 있는 PC에서 돈다. 화면 없는 서버는 지원하지 않는다.
- 여러 PC에 설치해서 비서 하나로 쓸 수 있다.
- 비서는 주인 한 사람의 비서다. 주인하고만 대화하고, 다른 사람의 말은 참고 자료로만 쓴다.
- 주인은 채팅창과 Slack, Telegram, Discord 같은 채널에서 말을 건다. 어디서 말하든 같은 대화로 이어진다. 자세한 내용은 [세션](../architecture/sessions.md)에 있다.
- 주인의 서비스는 주인 계정 권한의 MCP 도구로 연동한다.
- 메인 세션은 서브 세션을 만들어 일을 맡기고 결과만 받는다.
- 비서가 내용을 정해서 다른 사람에게 하는 행동은 주인에게 확인받는다.
- 메모리는 핵심 기능이다.
- 의존성과 자원 사용을 작게 유지한다.
- LLM 프로바이더를 바꿔 쓸 수 있다.
- 서브 세션은 LLM API를 연결해서 dotori가 직접 실행하거나, 사용자가 쓰는 코딩 에이전트에 맡길 수 있다.
- 브라우저 같은 공통 도구는 실행 방식과 상관없이 같은 것을 쓴다.
- 브라우저 로그인 상태를 유지하는 것을 목표로 한다.
